# Code of Conduct

## Our pledge

We want participation in flavor_icon_ribbon to be free from harassment. This applies to issues, pull requests, and any other project space.

## Expected behavior

Be respectful and specific. Critique the change, not the person. Accept that maintainers may decline a change that falls outside the package's scope.

Harassment, personal attacks, and publishing someone else's private information are not acceptable.

## Enforcement

Report conduct that breaks this standard to the maintainers through a [private GitHub security advisory](https://github.com/tutttuwi/flavor_icon_ribbon/security/advisories/new). Maintainers may edit or reject contributions, and may block further interaction with the project.
