# Security

flavor_icon_ribbon is a local development tool. It reads a YAML config and PNG files under that config's directory, and it replaces launcher PNGs there. It does not open a network connection.

## Reporting a vulnerability

Report a security issue privately through [GitHub security advisories](https://github.com/tutttuwi/flavor_icon_ribbon/security/advisories/new). Do not open a public issue for an unfixed vulnerability.

Include the package version, the impact, and a way to reproduce the problem.

## Supported versions

Security fixes go into the latest release published on pub.dev.
